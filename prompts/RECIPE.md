# 実写にしか見えない商品写真をAIで作るレシピ

元ネタ: 2026-09-22 のクリップ履歴に残っていた「ミニけし」プロンプト。
gpt-image-2 で再現・検証済み（`images/01_minikeshi.png`）。

## 核心

**AIっぽさは「きれいすぎること」から来る。だから欠陥を具体的に指定する。**

「リアルに」「写真のように」と書いても効かない。効くのは、現物にある
物理的な欠陥を名指しすること。以下は実際に効いた指定。

| 効く指定 | 何が起きるか |
|---|---|
| 印刷ズレ・インクのムラ | 版ズレが再現され、量産品の安っぽさが出る |
| 完全マットなラバー素材 | CG特有のテカリが消える |
| 微細な粒子・粉・削れ・摩耗 | 手に取られた痕跡が出て「実在」する |
| ビニールのシワ・曇り・静電気で張り付く | 透明素材がCGっぽさの最大の敵。シワ指定で解決 |
| 一部空気が入ってふくらみ | 袋が立体になる |
| シール部分に軽いヨレ | 人が貼った感じが出る |

## 禁止指定（これを書かないと勝手にきれいになる）

```
Avoid: glossy plastic rendering, luxurious finish, perfectly flawless printing
```

「高級すぎる質感（安っぽさが正解）」を明示する。AIの既定は「良く見せる」なので、
逆方向に引っ張らないと中央値に戻る。

## 構図で効いたもの

- 主役はパッケージ、中央に置く
- 周囲に中身が少しこぼれている
- 1〜2個は袋から出ている
- **指先が1つをつまもうとしている** ← これが一番「生活の中の物」にする
- 一部フレームアウトさせる（完璧な収まりを崩す）
- 蛍光色など目立つ個体を1つだけ混ぜて視線誘導

## 情報要素（リアリティの最後の1割）

実在する商品には必ず載っている情報を入れる。

- JANコード（バーコード）
- 対象年齢の表記
- 注意書き（「食べられません」等）
- 「全◯種」「ランダム封入」
- 会社名
- MADE IN JAPAN / CHINA

## 落とし穴（1回目で踏んだ）

**架空の会社名を明示しないと、AIが実在企業名を書く。**
1回目の生成で実在の玩具メーカー名がパッケージに入った。プロンプトに
架空社名を名指しで指定し、かつ実在名を禁止すること。

```
the company name must be exactly the fictional 「株式会社◯◯」
(do NOT use any real company name such as A, B, C)
```

キャラクター物は既存キャラに寄る危険があるので、配布用素材では
キャラクターを避けて食品・日用品・店の小物にする。

## 雛形（JSON）

```json
{
  "subject": "何の商品か。素材と、そこにある摩耗・欠けを具体的に",
  "package": "包材の種類と、シワ・曇り・空気・ヨレ・印刷ズレ",
  "graphic_design": "デザインの系統・配色・書体・ロゴ文字列",
  "info_elements": "バーコード・注意書き・架空社名・原産国",
  "composition": "主役の位置・こぼれ・指先・フレームアウト",
  "lighting": "自然光・ややハイキー・柔らかい影",
  "camera": "マクロ寄り・浅い被写界深度・中央シャープ",
  "background": "白〜パステルの面・シンプル",
  "avoid": "テカリ・高級感・完璧な印刷・実在ブランド",
  "output": "実在する商品にしか見えないレベル"
}
```

## 使うとき

- 生成は `mcp__openai-chat__generate_image` の `model: "gpt-image-2"`、`quality: "high"`
- 1枚あたり2〜3分かかるのでバックグラウンドに回る
- **生成後は必ず開いて目視する**。社名・文字化け・キャラの寄りを見る
