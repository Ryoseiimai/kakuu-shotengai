# 架空の商店街

実在しない店・商品のAI生成写真5点と、実写に見せるためのプロンプトの作り方。

「載せる写真がない」という理由だけでホームページを諦めていた人が、まず1枚置くための素材です。

- 公開ページ: https://ryoseiimai.github.io/kakuu-shotengai/
- 画像: `images/` （JPEG・原寸）／ `originals/` （PNG）
- 作り方: [prompts/RECIPE.md](prompts/RECIPE.md)

## 使っていいこと

見本サイト・練習・提案の仮置きに自由に使えます。クレジット表記も改変の許可も要りません。

## だめなこと

**実在する店の「うちの商品」としては使わないでください。** 写っている店・商品・社名はすべて架空です。売っていない物の写真を載せると、お客さんを騙すことになります。
